简历优化 checklist ​

📝 内容完整性 ​

  • 个人信息（姓名、电话、邮箱、GitHub、博客）
  • 求职意向（明确写明"Laravel 后端开发"）
  • 技术栈（关键词 + 掌握程度）
  • 项目经验（至少 3 个高质量项目）
  • 工作经历（倒序排列，包含公司名、职位、时间）
  • 教育背景
  • 附加信息（证书、竞赛、爱好 - 可选）

📝 格式排版 ​

  • PDF 格式输出（不要用 Word）
  • 文件大小控制在 1MB 以内
  • 页边距适中（左右各 2cm）
  • 字体统一（中文用思源黑体，英文用 Roboto）
  • 字号合理（标题 14pt，正文 10-11pt）
  • 行间距适中（1.2-1.5 倍）
  • 没有错别字！
  • 没有多余的空行！

📝 针对性调整 ​

投递每个岗位前，确保：

  • 对照 JD 重新审视简历，补充匹配关键词
  • 删除与岗位无关的经历（如投递 Laravel 岗，弱化 Java 经验）
  • 调整项目顺序，把最相关的放前面
  • 量化指标是否符合对方期望的规模
  • 添加行业术语（如对方是医药行业，强调 GMP 经验）

markdown

最终报表响应时间从 45 秒降低到 18 秒，

不同经验的简历侧重点 ​

🟢 应届生/初级（0-2 年经验） ​

突出：

  • ✅ 学习能力（自学项目、技术博客）
  • ✅ 基础扎实（数据结构、算法、计算机网络）
  • ✅ 潜力（竞赛获奖、开源贡献）
  • ✅ 实习经历（即使只有 3 个月也要写）

弱化：

  • ❌ 管理经验
  • ❌ 大型项目经验（诚实说明）

🟡 中级（3-5 年经验） ​

突出：

  • ✅ 独立承担模块开发的能力
  • ✅ 技术难点攻克案例
  • ✅ 性能优化、Bug 修复记录
  • ✅ 团队协作、Code Review 经验

可以提及：

  • ⚠️ 带新人经验（即使只是 Mentor）
  • ⚠️ 技术选型决策过程

🔴 高级（5 年以上） ​

突出：

  • ✅ 架构设计能力（单体 → 微服务）
  • ✅ 技术领导力（Team Leader 经验）
  • ✅ 业务理解深度（不仅仅是写代码）
  • ✅ 跨部门沟通能力

必须有：

  • 💰 成本意识（ROI分析）
  • 💰 风险管理（容灾、降级、预案）
  • 💰 人才培养（梯队建设）

最后的黄金法则 ​

✅ Do's（应该做） ​

  1. 一页纸原则：除非超过 10 年经验，否则尽量压缩到一页
  2. STAR 原则：用情境 - 任务 - 行动 - 结果描述项目
  3. 数据说话：尽可能量化成果
  4. 针对岗位：每次投递前微调关键词
  5. 真实可信：不要编造，面试很容易露馅

❌ Don'ts（不应该做） ​

  1. 写满 5 段自我评价废话
  2. 列出不会的技术名称
  3. 出现拼写错误、错别字
  4. 格式混乱、排版不统一
  5. 过于谦虚或过度吹嘘
