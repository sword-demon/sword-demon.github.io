# 如何留下好映像

- 确保不会流行坏映像
- 注意面试礼仪
- 让面试官感觉到你和其他候选人的区别



## 面试礼仪

- 守时，预留半小时，如果无法避免，提前沟通
- 见面问好，离开道谢
- 多用礼貌用语：请，谢谢
- 主动破冰，自我介绍要有亮点
- 避免刻意讨好的拍马屁
- 不要过分展示自己，过于夸大



## 事实和观点的区别

> 当时我遇到了一个技术难题，xxx (描述具体遇到的问题)，当时小组有 2 位同事先后尝试去解决这个问题，花了一段时间没有明显的进展。然后我主动去了解了这个问题，查看了相关源码，定位到了具体的问题，发现是 xxx 原因导致的，然后对这个问题进行了修复。



当时项目遇到了一个技术难题，xxx，当时团队里没人能搞定这个问题，最终是我定位到问题并修复的。【夸大】



## 体现你的不同

- 精心准备面试
- 突出自己的特点【技术上、项目上，解决了某个难度的问题，或者开源项目】，面试前深入的准备
- 表达对细分行业或者企业的喜欢



> 了解到贵公司是做 xxx 的，我对这方面很感兴趣，希望有机会在这个行业发展

【需要提前了解这个行业的知识，面试官可能会让你谈谈企业的文化或价值观】



## 冰山模型

### 概念

![image-20260919234922106](https://virusoss.oss-cn-shanghai.aliyuncs.com/image-20260919234922106.png)

冰山以上的素质

- 知识
- 技能

冰山以下的素质

- 价值观，两难问题的立场来判断
- 社会角色，自我形象和自我认知
- 个性，个人的思维方式，做事的风格，性格，适应能力
- 动机，个人对特定领域的想法



面试的阶段考察的素质不同

- 一面主要考察候选人能不能干活，也就是对知识和技能的考察
- 二面主要考察的是候选人是不是可培养，着重考察候选人的潜力
- 三面主要考察候选人的价值观，看候选人能干多久



### 对于求职者的意义

- 明确非技术类问题的出题方向和意图
- 重视冰山以下的部分的能力展示



### 如何应对冰山以下的问题

- 价值观方面：组织利益要优先于个人利益；长期利益要优先于短期利益，在不影响企业需求的情况下兼容个人需求
- 自我形象和认知层面：需要表现出愿意学习，愿意探索未知的领域，把失败当做经历而非结果。
- 个性方面：表现出自己的适应能力，能调整自己的风格，更快的适应团队
- 动机方面：尽可能表现出对企业和业务的兴趣和对技术的追求



## 面试秘笈

- 面试前：投入最多精力的地方，主动去总结
  - 精心制作简历，并选择合适的投递渠道
    - 各大招聘网站 ，拉钩，boss 直聘
    - 公司网站
    - 线下招聘会
    - 社交平台，公司的微博或公众号
    - 猎头【说明企业对人才的需求较大】
    - 内推 **优先考虑内推**
  - **参加面试前，详细了解企业的情况**
    - 企业基本信息，所属的行业，发展前景，行业中的位置
    - 创始人的背景
    - 企业的核心产品，盈利情况
    - 企业的价值观使命和愿景
    - 你面试的部门对企业的价值或者企业里的地位
    - 企业认为我的哪些方面比较适合这个岗位
    - 项目组人数，主要业务，技术栈，团队技术氛围咋样
    - 直接汇报的对象的岗位
  - 做好充分的面试准备
    - 面试开始前的准备
      - 着装得体
      - 保持微笑和良好的心理状态
      - 充分休息，带上打印好的简历
    - 技术面试的准备，投入最多精力的
      - 简历上出现的知识点一定要准备扎实，进行系统的梳理
      - 准备好项目相关的面试问题和答案
      - 算法面试
      - 介绍你最近/最有成就感/最困难的项目
      - 介绍下你处理过的最难的技术问题
      - 介绍一个你犯过的技术问题或者造成的故障
      - 根据 star 提问法，针对每个项目提问以及答案
      - 展示自己在项目中的重要性
        - 针对复杂需求设计了什么方案，难点是什么？怎么解决的 ？
        - 项目最终达到什么样的成果？自己发挥着什么样的角色？
        - 项目完成后你总结了什么经验？有哪些不足？有什么改进方案？
        - 养成整理和记录的习惯
        - 找那些能让自己简历有亮点的工作
    - 非技术面试的准备
      - 根据岗位要求准备自我介绍【面试的第一阶段】
        - 精心准备、按需调整、表现**匹配度**和**亮点**
        - 表达对行业，企业，业务或技术的兴趣
        - 自我介绍控制在 2 到 3 分钟，简历上有的东西要简化或一笔带过
      - 提前准备冰山以下部分的面试题
  - 多进行模拟面试
    - 多面试找状态
    - 多面试找不足
    - 可以自己找朋友充当面试官，或者找镜子
  - 注意行为细节，避免扣印象分，紧张的时候会有小动作
  - 注意沟通效率，结果先行
  - 向面试官提问要恰当
    - 询问一些关于团队或项目，以及网上获取不到的信息
- 面试中
  - 避免挤牙膏式的问题
  - 需要自己要问什么，以及问什么合适
- 面试后
  - 总结和复习
  - 对没回答出来的面试题进行补救



## 简历的针对性

### 技能的针对性

- 通过招聘企业的岗位描述信息获取
- 直接咨询企业
- 咨询企业内部的员工或者猎头

### 业务背景的针对性

- 突出与企业岗位相似的业务经验

### 价值观的一致性

- 在简历的个人评价中可适当加一些符合企业价值观的特质，准备匹配这些特质的事，至少准备一件事来说明你有这个特质



## 大厂眼中的好简历

### 标准的简历结构

- 基本信息
  - 姓名
  - 手机号
  - 邮箱
  - 年龄
  - 求职意向
  - 期望工作地点
- 教育经历
  - 大学及以上的学历
  - 包括学校名称、专业，以及起止时间
  - 如果学历不好，可以放到后面，个人评价之前
- 专业技能
  - 技能点+掌握程度【精通、熟悉、掌握、了解】
  - 技术栈【有实际项目经验的编程语言】
  - 业务能力
  - 软技能【学习能力、管理能力等】
  - 给面试官出题范围，将面试官引导到自己熟悉的领域，但是自己熟悉的领域你也要提前熟悉了解
  - 这里的技能点一定是深入掌握的，最好是看过源码的
  - 突出你与职位的匹配度
- 实习/工作经历
  - 实习/工作的企业，在企业的工作的起始时间以及成功
  - 按照时间倒序展示
- 科研/项目经历
  - 参加的项目介绍，项目的起止时间，主要职责
  - 遇到的挑战以及产出的成果
  - 使用时间倒序展示
  - 在xxx情况或 xxx 背景下，为了解决 xxx 问题或者达到 xxx目标
  - 我通过 xxx 方法或者技术最终获得了 xxx 成功，最好量化的指标，突出项目成功
- 个人评价
  - 专业特长、性格、做事风格
- 技能证书/获奖经历（非必须）
  - 专业证书或者外语证书
  - 大厂的项目大奖
  - 一般放到个人评价之前



## 简历优化的建议

- 慎用精通
- 突出个人亮点，如何发现项目的问题，以及如何解决的，项目的架构选型，为什么这么选，与其他的相比有什么优势
- 确保简历上的每个技术点你都有比较系统的了解
