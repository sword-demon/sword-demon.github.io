# SWOT 态势分析法

## 概念

> 用来确定企业自身竞争优势、劣势、外部市场的机会和威胁，从而将公司的战略与公司内部资源、外部环境有机结合起来的一种科学的分析方法。

- Strength：优势
- Weakness：劣势
- Opportunity：机会
- Threats：威胁



## 案例

- 个人做技术`Leader`能力分析（工作 3 年，高级 java，技术能力不错，项目组长刚离职）
  - 优势：技术不错、对公司业务熟悉（个人内部）
  - 劣势：项目管理能力不足、PPT 汇报能力不足（个人内部）
  - 机会：独立负责的项目把控、直接和领导汇报、成为管理层（公司外部）
  - 威胁：项目的规范机制还没有建立、项目的核心难点还没攻破、加班比较多（公司外部）

- 技术解决方案分析（团队熟悉 RabbitMQ、新来的组长熟悉 RocketMQ，技术选型考虑）
  - 优势：RabbitMQ 团队多人使用过、AMQP 跨语言、模型 API 丰富（团队内部）
  - 劣势：阅读过源码的人较少，Erlang 开发，二次修改不容易，项目组长对这个不熟悉（团队内部）
  - 机会：项目可以快速上线，减少踩坑（团队外部）
  - 威胁：未来可能有更强大的 MQ 产品出现或公司改动架构（团队外部）



**总结：根据 SWOT 进行充分分析，然后进行取舍选择，考虑更全，做事回答就会更有条理了**
