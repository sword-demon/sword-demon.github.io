# workbuddy 使用

## 知识星球自动化运营

> 安装你的星球skill：上「workbuudy」—点「专家」—「连接器」—「知识星球」—即可安装知识星球SKill—实现你的星球自动化运营



**提示词**



```
星主专属提示词/复制发 AI 大大减少你星球运营工作量

1.每日巡场摘要｜提示词:

帮我巡检【星球名】近 7 天内容，输出管理员周报：1）高质量内容；2）需要回复的用户问题；3）疑似广告/灌水/测试内容；4）建议设精华；5）建议加标签；6）建议删除或隐藏的内容。每条给理由和处理建议，先不要执行。

2.高热帖评论区分析｜提示词:

帮我分析这条知识星球主题下面的评论，按点赞数和观点类型整理。找出评论区里重复出现的问题，给我一份统一回复建议。把评论分成：支持、反对、补充案例、提问、无效内容。【主题链接】

3.批量内容发布｜提示词:

帮我把下面这些内容整理成适合知识星球发布的主题，统一标题格式和结尾互动问题，生成待发布清单，先不要发，给我确认后再逐条发到【星球名】。

4.批量精华推荐 + 执行｜提示词:

帮我看【星球名】最近 10 条主题，按"适合长期沉淀、适合新用户阅读、适合引发讨论"三个标准，挑出最值得设精华的 10 条。输出排序、理由，等我确认后再设精华。

5.反垃圾广告巡查｜提示词:

帮我巡查知识星球【星球名】最近 100 条内容，找出疑似广告。不要自动删帖，先把疑似广告、判断理由和原文整理成表格，分成：保留、待人工复核、建议删除三类。
```
