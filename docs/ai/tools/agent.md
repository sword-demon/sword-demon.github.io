## 智能体：能自主干活的 AI 实体

> 基本定义：能够感知环境、进行决策并采取行动，以实现特定目标的自主实体系统。

- 感知：获取外部环境信息，如读取文档、接收语音、联网搜索
- 决策：基于“大脑”的分析与推理，拆解复杂任务并规划出下一步具体的行动路径
- 执行：调用工具、API 或代码，对环境产生实际影响，如撰写邮件、编写代码。



### 四个核心组件

- 目标：指导智能体行为的最终目的
- 记忆：包含短期记忆（对话上下文），与长期记忆（历史经验）
- 工具：调用外部工具执行任务，如搜索引擎，天气 API 等
- 行动：基于目标、记忆和工具、执行的具体步骤与反馈



### 多智能体：模拟团队分工的 AI 系统

- 规划者 planner：拆解大目标为具体可执行的小任务，指定执行规划
- 执行者 executor：负责搜集资料、编写代码、生成文案，落地具体工作
- 审查者 reviewer：负责检查结果、挑错、找 bug，不合格打回重做

协作方式：智能体之间通过标准化的消息传递机制沟通，并共享“环境/记忆池”来同步任务进度与信息。
