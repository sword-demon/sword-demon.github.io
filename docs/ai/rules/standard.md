## 项目整体架构通用规范

1. 项目必须按功能模块拆分，禁止编写超大单体文件
2. 通用工具、公共方法统一抽离封装，全局复用
3. 业务逻辑和页面、接口入口分离，不把所有的逻辑写在入口处
4. 目录结构清晰，同类文件统一归类存放



## Vue3 开发规则

1. 统一使用 Vue3 script setup 组合式 API
2. 组件大驼峰命名，变量方法小驼峰命名
3. 接口请求统一封装，不在页面内直接写请求代码
4. 页面和通用组件拆分，可复用逻辑抽离组合式函数
5. 严格按目录分层：页面、组件、接口、工具分开存放



## Python FastAPI 开发规则

1. 遵循 Python 基础命名规范，变量和文件使用下划线命名
2. FastAPI 按路由模块化拆分，不同业务分开路由文件
3. 数据模型、路由接口、业务逻辑分层编写
4. 统一接口返回格式，参数做好基础校验
5. 业务逻辑抽离到单独方法，路由只做接收和响应
